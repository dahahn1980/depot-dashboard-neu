# Depot Dashboard

Interaktives Depot-Dashboard für GitHub Pages.

## Dateien

- `index.html` – Seitenstruktur
- `style.css` – Gestaltung
- `app.js` – Diagramme und Interaktion
- `data.js` – Depotdaten
- `.nojekyll` – verhindert Jekyll-Verarbeitung

## GitHub Pages aktivieren

1. Repository in Safari öffnen
2. `Settings`
3. `Pages`
4. Unter **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. `Save`

Danach ist die Seite erreichbar unter:

`https://dahahn1980.github.io/depot-dashboard-neu/`
